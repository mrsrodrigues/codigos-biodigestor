# Início Rápido

## 1. Preparar o ambiente
- Instale o Arduino IDE.
- Adicione suporte para ESP32.
- Instale as bibliotecas usadas no sketch.

## 2. Ajustar o código
Abra o sketch do projeto e troque:
- SSID do Wi-Fi
- senha do Wi-Fi
- token de autenticação do Blynk

## 3. Enviar para a placa
- Conecte o ESP32 no USB.
- Selecione a placa ESP32.
- Selecione a porta correta.
- Clique em Upload.

## 4. Montar o circuito
Use o arquivo [CONEXAO_PINAGEM.md](CONEXAO_PINAGEM.md) para conferir as conexões.

## 5. Usar o app Blynk
- Crie um projeto no Blynk.
- Escolha ESP32 e Wi-Fi.
- Adicione widgets para mostrar os valores.
- O app passa a mostrar os dados do sistema.

## 6. Guardar os dados
Os dados ficam na placa e também podem ser exportados para Excel.

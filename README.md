# Documentação do Biodigestor

Esta pasta contém apenas o básico para usar o sistema.

## Arquivos principais
- [INICIO_RAPIDO.md](INICIO_RAPIDO.md): passos para ligar e testar.
- [CONEXAO_PINAGEM.md](CONEXAO_PINAGEM.md): ligação da placa e dos sensores.
- [LOGGING_DADOS.md](LOGGING_DADOS.md): como salvar dados na placa e abrir no Excel.

## Resumo simples
1. Monte a placa.
2. Carregue o código no ESP32.
3. Configure Wi-Fi e Blynk.
4. Use o app Blynk para ver os valores.
5. Os dados ficam na placa e também podem ir para Excel.
